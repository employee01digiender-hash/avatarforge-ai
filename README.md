# ✨ Overview

AvatarForge AI allows users to upload their images and generate personalized 3D avatars using artificial intelligence.

The project focuses on combining:

- 🤖 Artificial Intelligence
- 🎨 3D Graphics
- 🌐 Web Technologies
- 🧍 Digital Identity Creation


The current version is a frontend prototype with a scalable architecture prepared for future AI model integration.
